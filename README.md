# Video Live Wallpaper — Eco patch (experimental)

Unofficial source modifications for CodeG0blin's Video Live Wallpaper, Apache-2.0.
Upstream: https://github.com/codeg0blin/video-live-wallpaper (v1.3.0; source inspected on main, exact patch anchors are checked before any file is changed).

## Behaviour
- Double-tap empty wallpaper space to toggle a persistent manual pause across active wallpaper engines. The system picker preview ignores the manual toggle. A launcher or lock screen can intercept double taps, especially if double-tap-to-sleep is enabled.
- Play only while visible, interactive, not in Battery Saver and below severe thermal status. Automatically resume only if not manually paused. No polling, wake locks, network permission or additional dependencies.
- Preserve last displayed frame on pause when the surface remains intact; try a single paused seek for a poster on surface recreation. A codec may instead show a black frame until playback starts.
- Retain source dimensions for paused redraws and coalesce queued video frame draws. Avoid starting an invisible player to apply speed preferences; apply on resume instead. Retain upstream's existing event-driven rendering and bounded retries.
- GIF support retained; a first still frame is requested when initially paused.
- Separate app ID (`io.github.codeg0blin.videowallpaper.eco`) avoids signing conflicts with official builds. Minimum Android version changed to Android 10 (API 29) for thermal callbacks. Both apps may have the same displayed name.

## Local build
Requires Python 3, JDK 17 and Android SDK 34.
```
git clone --branch v1.3.0 https://github.com/codeg0blin/video-live-wallpaper.git upstream
python3 apply_eco_patch.py upstream --check
python3 apply_eco_patch.py upstream
cd upstream
bash gradlew testDebugUnitTest assembleDebug
```
The APK should be at `upstream/app/build/outputs/apk/debug/app-debug.apk` if the build succeeds. Keep original attribution, LICENSE and NOTICE files. This is not an official F-Droid build.

## Build without a computer
The included `.github/workflows/build.yml` is an optional GitHub Actions workflow. Put the Python script and workflow into a separate GitHub repository, keeping the paths exactly as supplied. From GitHub in your mobile browser, open Actions > Build Eco Wallpaper > Run workflow. If it succeeds, download the ZIP artifact, extract the APK, and install it. Debug signing keys generated by separate workflow runs can differ, so installing an update may require uninstalling the earlier debug build. Keep Play Protect enabled. No build has been run by the author of this patch.

## Verification required
- Test double tap in empty launcher space, not on icons. Disable launcher double-tap-to-sleep if it conflicts. Test play/pause, screen-off/on, foreground app/home, wallpaper surface recreation, battery saver on/off, changing media and speed, and both GIF and MP4. Test thermal response with Android's test facilities rather than deliberately overheating a phone.
- Check battery usage and temperature under comparable conditions over 24 hours; no actual battery or heat savings have been measured. An idle process or retained decoder/texture may still occupy RAM. Screen visibility and launcher touch delivery vary by firmware.
- Python syntax checked only. The upstream repo could not be downloaded into the build environment and no Android SDK was available, so the exact source patch application, compilation, APK installation and runtime behavior remain unverified. The workflow fails if source anchors differ. No signed installable APK is included.
